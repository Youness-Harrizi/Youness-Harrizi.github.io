# Active Directory 101: DPAPI (Data Protection API)
*Extracting Windows Secrets*

---

## What is DPAPI?

<div class="key-concept" markdown="1">
**DPAPI = Data Protection API**
</div>

The Data Protection API is a Windows feature that allows applications to store sensitive data securely:

- Allows various applications to store **sensitive data** (passwords, certificates, etc.)
- Data is stored in the user's directory and secured by keys derived from the user's password
- Storage location: `C:\Users\$USER\AppData\Roaming\Microsoft\Protect\$SUID\$GUID`

<div class="warning-box" markdown="1">
🎯 **Attacker Goal:** Extract and decrypt DPAPI-protected secrets to find passwords, tokens, and certificates!
</div>

---

## What Data Can We Extract?

DPAPI protects a treasure trove of sensitive information across different categories:

### 🌐 Browser Data
- **🔐 Chrome/Edge credentials** - Saved passwords and login data
- **🍪 Cookies & tokens** - Session authentication tokens
- **🔄 Chrome refresh tokens** - OAuth refresh tokens
- **🦊 Firefox saved passwords** - Mozilla credential store
- **📊 Session data** - Active browser sessions

### 📶 Network & System Data
- **📶 WiFi passwords** - Wireless network credentials
- **🖥️ VNC credentials** - Remote desktop passwords
- **🔒 VPN configurations** - VPN connection details
- **📜 Windows certificates** - System and user certificates
- **📁 Desktop files & recent documents** - User file access

### 🛠️ Application Data
- **🖥️ MobaXterm credentials** - SSH/terminal passwords
- **🖥️ RDP saved passwords** - Remote desktop credentials
- **🔑 SSH keys** - Private key files
- **🗑️ Recycle bin files** - Deleted but recoverable data
- **💾 Cached credentials** - Application-stored passwords

## 📜 Certificate Extraction & Usage

### Certificate Attack Flow

1. **Find Certificate** - DonPAPI extracts .pfx files
2. **Get TGT** - Use certificate for Kerberos auth
3. **Extract Hash** - Retrieve NT hash from TGT

### Certificate Authentication

```bash
# Use extracted certificate for authentication
proxychains certipy auth -pfx '/home/auditor/.donpapi/loot/192.168.56.11/winterfell.north.sevenkingdoms.local_953B926BB18D96AB.pfx'
```

## 🛡️ Defense Strategies

<div class="warning-box" markdown="1">
**⚠️ Defense Strategies:**

- **Enable Credential Guard** - Hardware-based credential protection
- **Use hardware-backed certificates** - TPM-based certificate storage
- **Implement proper endpoint protection** - EDR and behavioral monitoring
- **Monitor for unusual DPAPI access** - Detect bulk credential extraction
</div>

### Detection Methods

- Monitor for mass DPAPI blob access
- Watch for unusual certificate usage patterns
- Detect browser credential database access
- Alert on multiple authentication attempts with extracted credentials
